# Channel rules and prohibitions

Verified by the ferryx-gtm review on 2026-10-24 (same owner, same accounts). Re-check right before posting.

| Channel | Key rules | Our approach for mhc |
|---|---|---|
| Hacker News (Show HN) | Must be something people can try; no vote requests; **no LLM-written posts or comments**; no delete-and-repost ([showhn](https://news.ycombinator.com/showhn.html), [guidelines](https://news.ycombinator.com/newsguidelines.html)) | Human-written. Title names what it is, body credits upstream and links the reproducible benchmark. 10/27 22:00 KST |
| r/rust | Must be a Rust topic; AI-generated and low-quality posts removed | Technical post on the port and memory model only |
| r/LocalLLaMA | Self-promotion <= 10% of activity, disclose affiliation, no LLM-generated posts | Only with an Ollama/local-model angle |
| r/programming | No "I made this" posts | Benchmark-method write-up only, after 10/27 |
| r/opensource | Linked code must have an OSI license | **Not used** (SUL-1.0 parts) |
| r/commandline | No generative-AI projects, no projects under 30 days old | **Not used** |
| GeekNews (Show GN) | Links allowed 1 week after signup; own products via Show GN; no upvote requests | Only if the account qualifies |
| Lobsters | No self-promotion for 70 days after joining | Comments only |
| Korean Rust user group Discord | Server rules not yet read | Read #rules first; showcase channel only |
| Upstream issues/PRs (oh-my-openagent, senpi) | Project space, not ours | **No advertising.** Link only when asked, with disclosure |

## Prohibited everywhere

- "Full parity", unmeasured numbers, "faster" (wall time is equal)
- Posting agent-written text as is; vote/star requests; multiple accounts
- Omitting upstream credit
